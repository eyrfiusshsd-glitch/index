# Bix - تطبيق التواصل الاجتماعي

## نظرة عامة
Bix هو تطبيق تواصل اجتماعي شبيه بـ TikTok و Kwai و Instagram، مطور باستخدام Flutter. يوفر التطبيق تجربة مستخدم متكاملة مع ميزات متقدمة للفيديوهات القصيرة والتفاعل الاجتماعي.

## الميزات الرئيسية

### 🔐 نظام المصادقة
- تسجيل الدخول والتسجيل بالبريد الإلكتروني
- تسجيل الدخول عبر Facebook و Google
- واجهة مستخدم عربية بتصميم حديث

### 🏠 الصفحة الرئيسية
- تشغيل الفيديوهات القصيرة بشكل عمودي
- إمكانية الإعجاب والتعليق والمشاركة
- عرض معلومات المستخدم والوصف
- تشغيل تلقائي للفيديوهات

### 🔍 صفحة البحث
- البحث عن المستخدمين والمحتوى
- عرض المحتوى الشائع والترندينغ
- تصفح المستخدمين المقترحين
- فلترة النتائج حسب النوع

### 📹 إنشاء الفيديوهات
- تسجيل فيديوهات جديدة باستخدام الكاميرا
- إضافة فلاتر وتأثيرات
- أدوات تحرير متقدمة
- إضافة نصوص ووصف للفيديو

### 💬 نظام الرسائل
- محادثات فردية مع المستخدمين
- إرسال الرسائل النصية والصور
- إشعارات فورية للرسائل الجديدة
- واجهة محادثة سهلة الاستخدام

### 👤 الملف الشخصي
- عرض معلومات المستخدم الشخصية
- إدارة الفيديوهات المنشورة
- عرض المتابعين والمتابعين
- تحرير معلومات الحساب

### ⚙️ الإعدادات
- إعدادات الحساب والخصوصية
- إعدادات الإشعارات
- إعدادات اللغة والمظهر
- خيارات الأمان والحماية

## التقنيات المستخدمة

### Frontend
- **Flutter 3.24.3** - إطار العمل الرئيسي
- **Dart** - لغة البرمجة
- **GetX** - إدارة الحالة والتنقل
- **Provider** - إدارة الحالة الإضافية

### Backend & Services
- **Firebase Core** - الخدمات السحابية
- **Firebase Auth** - نظام المصادقة
- **Cloud Firestore** - قاعدة البيانات
- **Firebase Storage** - تخزين الملفات

### Media & Camera
- **Video Player** - تشغيل الفيديوهات
- **Camera** - التقاط الصور والفيديوهات
- **Image Picker** - اختيار الصور

### UI Components
- **Cached Network Image** - تحميل وعرض الصور
- **Shimmer** - تأثيرات التحميل
- **Flutter Spinkit** - مؤشرات التحميل
- **Staggered Grid View** - عرض الشبكة المتدرجة

### Utilities
- **HTTP & Dio** - طلبات الشبكة
- **Shared Preferences** - التخزين المحلي
- **Permission Handler** - إدارة الأذونات
- **Path Provider** - إدارة المسارات

## هيكل المشروع

```
lib/
├── constants/          # الثوابت والألوان
├── controllers/        # تحكم في البيانات والمنطق
├── models/            # نماذج البيانات
├── screens/           # شاشات التطبيق
│   ├── auth/          # شاشات المصادقة
│   ├── main/          # الشاشات الرئيسية
│   ├── search/        # شاشة البحث
│   ├── video_creation/ # إنشاء الفيديوهات
│   ├── messages/      # نظام الرسائل
│   ├── profile/       # الملف الشخصي
│   └── settings/      # الإعدادات

├── utils/             # أدوات مساعدة
└── widgets/           # مكونات UI قابلة للإعادة
```

## التثبيت والتشغيل

### متطلبات النظام
- Flutter SDK 3.24.3 أو أحدث
- Android SDK 34 أو أحدث
- Java 17 أو أحدث

### خطوات التثبيت
1. استنساخ المشروع
```bash
git clone <repository-url>
cd bix_app
```

2. تثبيت التبعيات
```bash
flutter pub get
```

3. إعداد Firebase
- إنشاء مشروع Firebase جديد
- إضافة ملف `google-services.json` إلى `android/app/`
- تفعيل خدمات Authentication و Firestore و Storage

4. تشغيل التطبيق
```bash
flutter run
```

### بناء APK
```bash
flutter build apk --release
```
